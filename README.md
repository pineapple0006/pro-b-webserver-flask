# Citat-webside

## Introduktion

På denne hjemmeside kan du tilføje, og søge i pre-eksisterende citater! :]

## Disclaimer

Kun testet i Python 3.14.7

## Installation

### 1. Create virtual environment:

```python
python3 -m venv ./.venv
```

### 2. Activate virtual environment:

- Windows (cmd.exe):

```cmd
.venv/Scripts/activate.bat
```

- Windows (PowerShell):

```ps
.venv/Scripts/activate.ps1
```

- Linux:

```bash
source .venv/bin/activate
```

### 3. Install requirements:

```pip
pip install -r requirements.txt
```

### 4. Run server:

```py
python3 app.py
```

### 5. Connect to webserver:

http://127.0.0.1:5000/

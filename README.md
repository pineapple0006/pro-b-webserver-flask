# Citat-webside

## Introduktion

På denne hjemmeside kan du tilføje, og søge i pre-eksisterende citater! :]

## Disclaimer

Kun testet i Python 3.14.7

## Installation

1. Create virtual environment:

```
python3 -m venv ./.venv
```

2. Activate virtual environment:

- Windows (cmd.exe):

```
.venv/Scripts/activate.bat
```

- Windows (PowerShell):

```
.venv/Scripts/activate.ps1
```

- Linux:

```
source .venv/bin/activate
```

3. Install requirements:

```
pip install -r requirements.txt
```

4. Run server:

```
python3 app.py
```
